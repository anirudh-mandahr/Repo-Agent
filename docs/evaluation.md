### Request budget eval

`scripts/eval_qa.py` runs the QA scorer twice over `evals/qa.jsonl` (outer request budgets enabled vs disabled) and fails if any tier's citation-precision or groundedness drops. Truncation order under a tight prompt budget is scored with `repo_root` (and the graph when available) so Sources `file:line` citations actually resolve — a 0% figure next to a 1.00 was a scorer bug, not a measurement. Latency p50/p95 on the enabled run use `core.eval.model_bakeoff.percentile`. `make eval` is **provider: offline (stub answers — routing/retrieval only)**; `make eval-live` regenerates the scorecard below with a live LLM over all 50 labelled cases in `evals/qa.jsonl` (including trap and multi-turn).

- **Answer:** Dependency injection in this codebase (FastAPI) works via a special mechanism where dependencies are declared as callables (like functions or classes) and are then automatically called by the framework to inject their return values into path operation functions (endpoints). This is primarily achieved through the `Depends` construct. ### How Dependency Injection Works - **`fastapi.param_functions.Depends`** is a factory function used to declare a dependency. It takes a callable (dependency), an optional caching flag (`use_cache`), and an optional scope parameter. Calling `Depends` doesn't invoke the dependency directly but returns a marker object describing the dependency. - This marker object is an instance of the class **`fastapi.params.Depends`**, a frozen dataclass that holds the dependency callable, a flag indicating if the result should be cached during a request, and the scope of the dependency.
